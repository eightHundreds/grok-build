# 你的第一条提示

Grok Build 是一场和 agent 的对话：它可以读你的代码、运行
命令、编辑文件 — 就在终端里。

输入你想做的事，按 `Enter`。Grok 会把工作流式写入提示框上方的
**回看区**：回复、终端命令、文件编辑。

## 在 Grok 工作时继续输入

回合进行中再按 `Enter` 会**排队**下一条消息，而不是打断。
改主意了？在空提示上按 `Enter`，会停掉当前回合并立刻发送
队列里的消息。

## 你始终握着控制权

- **`Ctrl+C`** — 取消正在进行的回合（若有草稿，第一次只清空草稿）。`Esc` 不会取消；它会提醒你用 `Ctrl+C`。
- **空闲时 `Esc Esc`** — 清空提示；提示已空时改为打开回退选择器。误清了？`Ctrl+Z` 可以撤销。
- **`Ctrl+Q`** — 退出（VS Code 系终端用 `Ctrl+D`），按两次确认。

底部的**快捷键栏**始终显示当前情境下有用的按键 — 不确定时往下看。
