# 附加文件、图片与粘贴

你把上下文指得越准，Grok 的结果越好。有三种方式把内容放进提示：

## 用 `@` 提及文件

输入 `@` 打开模糊文件选择器 — 也支持行范围：

```
@src/main.rs          附加整个文件
@src/main.rs:10-50    附加指定行
@!.env                用 @! 访问隐藏文件
```

## 粘贴图片

把截图直接贴进提示：macOS 用 `Cmd+V`，Linux 用 `Ctrl+V`，
Windows 用 `Alt+V`。适合错误对话框、设计和示意图。

## 自己跑终端命令

在空提示上输入 `!` 可以直接跑终端命令 — 输出会出现在回看区，
Grok 也能看到。
