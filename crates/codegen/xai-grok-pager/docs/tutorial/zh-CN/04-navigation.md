# 熟悉界面

屏幕分成三块：**回看区**（对话）、下方的**提示框**，以及底部的
**快捷键栏**。待办和后台任务面板会在需要时滑入。

## 焦点

**`Tab`** 在提示框和回看区之间切换焦点。回看区获得焦点后，
可以用方向键移动选中项。

## 在对话里移动

- **`↑`/`↓`** — 选中上一条 / 下一条。
- **`Shift+←`/`Shift+→`** — 在回合之间跳转（你的提示）。
- **`PageUp`/`PageDown`** — 按页滚动；在提示框里也能用，不必先改焦点。
- **`←`/`→`** — 折叠 / 展开选中条目；很长的工具输出会先收起来。
- **`Enter`** — 在全屏查看器中打开选中条目。

## 面板

- **`Ctrl+T`** — 开关**待办面板**：Grok 对当前任务的实时计划。
- **`Ctrl+G`** — 开关**任务面板**：所有后台任务及其状态。

更习惯 vim 键？**`/vim-mode`** 会把回看区改成 `j`/`k`、`g`/`G` 等。
