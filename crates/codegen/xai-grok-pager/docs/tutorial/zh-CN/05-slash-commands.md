# 斜杠命令

在空提示上输入 `/`，会出现可搜索的命令下拉。第一天值得记住这几个：

| 命令 | 作用 |
|---------|--------------|
| `/help` | 浏览全部命令和键盘快捷键 |
| `/model` | 切换模型或推理力度 |
| `/resume` | 从上次会话继续 |
| `/new` | 开始新会话 |
| `/compact` | 压缩长对话以腾出上下文 |
| `/btw` | 给 Grok 发一句旁白，*不*打断当前任务 |
| `/rewind`（别名 `/undo`） | 把对话回退到更早的回合 |
| `/docs` | 完整使用指南，TUI 内或网页上 |
| `/feedback` | 向团队发送反馈 |

其中两个值得多看一眼：

- **`/compact`** 可以带提示：`/compact keep the auth details`。
  随时用 `/context` 查看上下文用量 — 窗口快满时 Grok 也会自动压缩。
- **`/rewind`**（或 **`/undo`**）把对话回退到更早的回合，丢掉之后的回合
  （文件改动保持原样）。

## 命令面板

按 **`Ctrl+P`**（或在回看区按 `?`）打开命令面板 —
一份可搜索的全部命令、快捷键和技能列表。完整快捷键速查在
`Ctrl+.`（若终端吞掉了，用 `Ctrl+X`）。

不用背：`/` 和 `Ctrl+P` 随时能告诉你有什么可用。

*深入阅读：`/docs Slash Commands`*
